# Chain marks

These marks identify Bitcoin, Ethereum, and Solana in the Blockchain infrastructure
chapter. The original artwork is unchanged; the renderer supplies a consistent
size and spacing beside the section name.

- `bitcoin.svg`: Bitboy's public-domain mark, via
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Bitcoin.svg).
  Copied from `tools/assets/bitcoin-logo.svg`.
- `ethereum.svg`: purple diamond from
  [ethereum.org brand assets](https://ethereum.org/assets/), specifically
  [eth-diamond-purple.svg](https://github.com/ethereum/ethereum-org-website/blob/dev/public/images/assets/svgs/eth-diamond-purple.svg).
- `solana.svg`: original gradient logomark from
  [Solana brand assets](https://solana.com/branding), specifically
  [solanaLogoMark.svg](https://solana.com/src/img/branding/solanaLogoMark.svg).

Retrieved 2026-10-08. Ethereum and Solana retain their respective marks; use here
identifies the subjects of the notes and does not indicate affiliation.
